# 证书

除 VLESS + Reality 外，其余四个协议都需要一份有效证书。EasySB 在面板自己的进程里通过 `go-acme/lego/v5` 向 Let's Encrypt 申请证书，使用 HTTP-01 standalone 校验：不需要下载 `acme.sh`，也不需要 socat 或其他监听工具。

## 申请流程

1. 填写域名与 ACME 邮箱，面板先做域名解析预检。
2. 停止 sing-box 内核，腾出 80 端口。
3. lego 在 80 端口应答 HTTP-01 挑战。
4. 取得证书后按「先写私钥、后写证书」的顺序落盘。
5. 重载内核与订阅服务。

预检会解析域名并比对本机公网 IP，把「域名当前指向哪里」作为事实报告给操作者。它不直接下结论：域名可以解析到 CDN 地址而仍然可以签发；但一条指向已下线主机的旧 A 记录会让整次签发失败，因此预检会提示其余解析地址，失败后也会指出具体是哪个地址无法访问。

::: tip
CDN（例如 Cloudflare 橙色云朵）会自己应答 HTTP-01，挑战请求到不了本机。这类失败通常表现为一个本机从未见过的 URL；检查域名解析是否直连本机。
:::

::: tip
`EASYSB_ACME_STAGING=1` 可以让整条流程走 Let's Encrypt 测试端点，证书不受信任但不消耗正式速率限制，适合先把域名试通。
:::

## 证书状态与操作

「域名管理」页面提供：

- 申请证书（含环境与解析预检）。
- 查看已签发证书及其到期时间。
- 切换激活域名。
- 删除某个域名的证书。
- 立即续期与续期定时器管理。

证书状态目录默认是 `/etc/sing-box/acme`，可用 `EASYSB_ACME_DIR` 覆盖。其中 `account.key` 与 `account.json` 保存 ACME 账号（`0600`），每个域名一个子目录，含 `fullchain.cer`（`0644`）与 `private.key`（`0600`）。

## 自签占位证书与 cert.Usable

在真实证书签发之前，面板会在 `/etc/sing-box/cert/` 生成一份自签占位证书，用来让内核配置始终可渲染、让面板能先跑起来。它只是占位：客户端会拒绝自签证书，所以订阅服务不会用它终结 TLS。

`cert.Usable(domain)` 是唯一的判断函数，它要求一份面板签发的真实证书，自签占位不算。订阅地址的协议（http / https）与订阅监听器加载的证书都问这同一个判断，因此两者不会各说各话。证书是否可用的判断与订阅服务的关系见 [订阅](/features/subscription)。

## 续期

续期按到期时间驱动：`cert.RenewBefore` 为 30 天，每晚一次续期检查会跳过还不需要续期的证书，不向 CA 发请求；一处续期失败不会阻断其他域名。

续期由面板自己的 systemd timer 驱动，单元会记录写入它的二进制路径，因此应由面板安装而不是在主机间复制：

```bash
# 安装续期定时器
easysb --install-renew-timer

# 移除续期定时器
easysb --remove-renew-timer

# 立即续期全部证书，仅在确有证书被续期时重载 sing-box 与订阅服务
easysb --renew-certs
```

续期单元 `easysb-acme.timer` 每天运行一次，带随机延迟；续期会在原位置替换证书对，所以「已续期但未重载」的内核仍在用旧证书，`--renew-certs` 正是为此重载服务。

## 速率限制与重复签发

Let's Encrypt 对同一域名一周只允许五张重复证书。EasySB 据此做了两件事：

- 当前证书仍在有效期内时，再次点击申请会直接返回成功并说明原因，不向 CA 下单；需要提前替换时先删除。
- 每晚的续期检查只对进入 30 天窗口的证书下单，其余跳过。

账号密钥文件与账号本身的关系：`account.key` 才代表账号，`account.json` 只是缓存了账号 URL。丢失 `account.json` 时，面板会用仍持有的密钥重新注册，拿回同一个账号；丢失密钥则意味着新账号。

## 模板里的证书路径

`templates/` 下协议样例中的 `certificate_path` 与 `key_path` 是示例值。部署由面板自动填成实际路径；手工使用时务必替换，并把文件权限收紧到 `600`。证书清单见 [配置模板](/config/templates)。

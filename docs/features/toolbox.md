# 工具箱

工具箱是「这台机器到底能干什么」的集中测量处：每项一个条目、每项一份报告，看板记住每项上次的结果。结果写在 `/etc/sing-box/easysb-toolbox.json`，关掉面板再打开仍然在。

**打开页面不会自动跑任何东西。** 测速、回程、跑分都不是按一下方向键就该开始的事；每项都要手动进入并启动。

## 四个分组

| 分组 | 条目 |
| :--- | :--- |
| 解锁检测 | 流媒体解锁（Netflix、Disney+、YouTube Premium、Prime Video、DAZN、TVBAnywhere+、Spotify、Reddit、TikTok）、AI 解锁（ChatGPT、Gemini、Claude）、区域解锁（Steam、Bilibili 三个区域、巴哈姆特動畫瘋） |
| 网络检测 | 三网回程、就近测速、三网测速 |
| IP 与端口 | IP 质量（多家数据库 + DNS 黑名单）、邮件端口（能否搭邮局） |
| 硬件与性能 | 系统信息、硬盘信息、CPU 跑分、内存测试、磁盘 IO（顺序 + 4K 随机）、多盘 IO |

各条目的 id：`unlock-media`、`unlock-ai`、`unlock-region`、`backtrace`、`speed-near`、`speed-cn`、`ipquality`、`portcheck`、`hw-info`、`hw-disk`、`bench-cpu`、`bench-mem`、`bench-disk`、`bench-disks`。

## 看板

看板是分组条目上方的那一块：它显示每个被选中的条目上次运行的结果与距今多久，从未运行过的条目显示「未检测」。`工具箱 → 看板设置` 可按分组或一次全选决定看板内容，选择结果随其他界面偏好写入 `easysb-ui.conf` 的 `BOARD=`。

从未设置过的面板显示默认条目（`tools.BoardDefault()`）：解锁检测三项、三网回程、IP 质量、系统信息。两条规则让看板可读：

- 一行一个条目，按注册顺序排列，不按「最近运行」重排。
- 只显示摘要的摘要，更多内容在条目自己的报告里。

全部关闭时看板会明确说明，与「空看板」区分开。

## 结论与地区

解锁条目的结论只有三个词，配一列「地区」，表格一行一个服务：

| 结论 | 含义 |
| :--- | :--- |
| 解锁 | 服务回了话，且它自己的答复说这个地址能用。 |
| 不解锁 | 服务拒绝了，或只接受一半（半能用不算能用）。 |
| 未知 | 答复读不出来：Cloudflare 挑战页、超时、页面里没有结论。原因写在表下的说明里，绝不猜成解锁。 |

「地区」列是各服务自己给出的判定，不是面板计算的。不同服务背后是不同的地理库，同一台机器被不同服务判成不同国家是常见现象。

::: tip
Prime Video 的店面页有几种形状，其中一种不含地理信息；探针会读到标记位并最多重试三次再判断。Claude 对数据中心地址返回 Cloudflare 挑战时记为「未知」，并附上从 `claude.ai/cdn-cgi/trace` 读到的地区，因为挑战说明 Cloudflare 不信任该地址，并不说明国家。
:::

## 界面与按键

工具箱沿用面板统一的固定布局：任何页面都是同一套上下两个框，尺寸与位置照主页面；条目多的页面在框内截断并写明还剩多少行，**面板不滚动**。跑起来时上下两框合成一个框，能算出总量的项给出真实进度百分比；报告表格过高时可在框内用上下键、PageUp/PageDown、Home/End 阅读。按键统一：

- **Q 在任何页面都直接退出面板。**
- **Esc 返回上一级**，返回只有这一个键。
- **Enter 只用于进入与确认**，不用于返回。

## 无终端环境

没有 TTY 时可用命令行运行同一批条目：

```bash
# 列出全部条目
sb --tool list

# 三网回程
sb --tool backtrace

# 流媒体解锁
sb --tool unlock-media

# 17 项解锁一次跑完的报告
sb --unlock
```

`sb --tool` 先打印条目名，再输出纯文本表格；失败时给出错误。命令行运行的结果同样会写入看板文件，所以面板里的看板能看到它。

## 数字来自哪里

工具箱不下载任何程序，每项都是本二进制里的 Go 代码：

- 解锁条目：每服务一至三个 HTTP 请求，由 `internal/unlock` 解析，不登录、不破验证码。
- 三网回程：本机 ICMP 探测（面板以 root 运行），再用 ip-api.com 查跳点的 ASN。
- 测速：通过 `github.com/showwin/speedtest-go` 走 speedtest.net，进程内运行；三网测速只筛选中国电信/联通/移动的服务器，海外主机常得到空列表，此时如实说明。
- IP 质量：九个无需密钥的数据库加十二个 DNS 黑名单。
- 邮件端口：对本机公网地址做 TCP 连接，并查 PTR 与 FCrDNS。
- 系统与硬盘信息：读 `/proc`、`/sys` 与挂载点；`systemd-detect-virt`、`timedatectl`、`smartctl` 仅在已安装时使用。
- 跑分：面板自己的 CPU、内存与磁盘工作负载，用标准库计时。

::: warning
CPU 跑分不是 geekbench 分数，磁盘数字不是 fio 结果，它们是面板自己的工作负载，只用于和另一台机器上的同一面板比较。项目前提是不安装外部程序，因此不会为了跑分去下载工具（没有 geekbench / sysbench / fio）。
:::
